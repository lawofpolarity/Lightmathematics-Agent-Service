# LM-AGENT-SERVICE-001 Benchmark Program

Status: **PROSPECTIVE / FROZEN-CONTRACT TESTING**

Goal: determine whether the complete governed reliance contract provides
decision-relevant capability beyond strong information-equivalent conventional systems.

## Stages
1. Historical regression across positive, null, adverse, falsification and boundary results.
2. Strong conventional comparator with equal information/instrumentation.
3. Paired-world and ablation tests, including negative controls.
4. Independent external-agent cohort after frozen sandbox deployment.

## Measurements
Decision correctness against predeclared case truth; false ALLOW; false REFUSE;
REVIEW/UNRESOLVED calibration; comparator agreement/disagreement; receipt
completeness; latency/cost; later Corrective Action Rate and Reliance Integrity Rate.

## Discipline
Preserve source/version identifiers; predeclare eligibility/scoring; conserve null
and adverse results; use strongest fair comparators; avoid circular metrics; never
attribute an information-equivalent result uniquely to LM.
